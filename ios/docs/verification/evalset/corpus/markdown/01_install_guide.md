# 安装

应用支持完全离线分析，不会上传文档。

安装后请先导入 `.litertlm` 模型，再导入资料文件。

## 系统要求

- iPhone，建议 8 GB 内存档位
- iOS 17 或更新版本

## 导入模型

通过「文件」App 选择本机已有的模型文件。模型不进入 Git，也不打进安装包。

# 使用

导入 TXT、Markdown、文本型 PDF 或 Office Open XML 后等待索引完成，即可提问。

提问范围可选择「全部资料」或指定文档。删除最后一个已选文档时，范围恢复为全部资料。

## 拒答

如果资料里没有足够依据，应用应明确拒答，而不是编造地址、政策或结论。
