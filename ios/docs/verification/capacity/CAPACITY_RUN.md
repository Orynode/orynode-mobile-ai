## 2. 强制终止 + 恢复（各一次）

对**同一文件**（或删库后重来）分别在约 10% / 50% / 90% 进度中断，再打开 → 点「重试索引」（不得重新选文件）。

**强杀后正确表现**：再次打开应看到 **失败 /「索引中断，请重试」**，而不是一直「正在索引」。  
强杀**不会**自动续跑；需点菜单 **重试索引**（不必重选文件）。

**进度不好目测时，用下面任一方式对准（推荐 ①）：**

1. **Debug 注入（最准）**  
   Xcode Scheme → Arguments：`-KBFailAtFraction 0.1`（再分别改 `0.5` / `0.9` 各跑一轮）。  
   触发失败后点「重试索引」应跑完。发版归档请注明「Debug 注入」；有余力再补 1 次真实强杀。
2. **按完整索引耗时换算**（你这次空库约 **2:52 ≈ 172s**）  
   - ~10% → 导入后约 **17s** 强杀  
   - ~50% → 约 **86s** 强杀  
   - ~90% → 约 **155s** 强杀  
   用手机计时器即可，差十几秒可接受。
3. **UI 仍显示「正在索引」时强杀**，并在备注写实际秒数；三档尽量拉开（前段 / 中段 / 末段）。
